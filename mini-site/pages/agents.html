AGENTS.md

Notes for Contributors (incl. AI Agents)

Docker Compose stack for a local API-governance demo (nginx "governance" registry + Swagger Editor + Backstage portal). No app code to build/test — this repo is config/docs/compose only.

Commands

  • make up / make down / make restart — manage the stack
  • make build / make build-no-cache — rebuild the Backstage image
  • make verify — curl all 5 acceptance endpoints, expect 200s
  • make logs / make backstage-logs / make governance-logs
  • make clean — full teardown incl. volumes and built images

Critical gotchas

Proxy: always verify with curl --noproxy '*' <url>, never PowerShell Invoke-WebRequest — proxy-aware tools route localhost through a corporate proxy and hang.

  • Backstage config is bind-mounted — just docker compose restart backstage after editing it. Only the Dockerfile requires a rebuild.
  • Catalog locations must be type: url, not type: file — the $text placeholder resolver needs a URL-schemed base.
  • HOST env var does nothing for the Backstage dev server; host binding is controlled only by app.listen.host/backend.listen.host.
  • governance/shared-models.yaml is served directly by nginx — edits take effect on refresh, no rebuild/restart needed.
  • Swagger Editor image is pinned to docker.swagger.io/swaggerapi/swagger-editor to dodge a mirror block.
  • Windows: if a file rename/move fails with "in use" after docker compose down, retry the down, or use robocopy /MOVE.

Contract-first governance practice

See the Contract-First page — the Spectral governance ruleset and a worked example using the real Tiwaz Bonds Management API.

Tiwaz's own repo/CI is read-only reference material — never edit files under repos/tiwaz; all governance artifacts live in this repo only.

Secrets rule: any real company/org name from source material (e.g. the original name behind "Company X" in the Decision Record) is treated as a secret in this repo and must always be replaced with a generic placeholder before anything is written to disk — never committed, even in quoted reference text.
